# useStore.ts — hooks tipados de Redux

Referencia real: `workspace/ptd-talento-front/src/hooks/useStore.ts`

## Qué es

Re-exporta `useAppDispatch` y `useAppSelector` **ya tipados** con los tipos del store.

```ts
// useStore.ts (referencia)
import { useDispatch, useSelector } from "react-redux";
import type { AppDispatch, RootState } from "../store/store";

export const useAppDispatch = () => useDispatch<AppDispatch>();
export const useAppSelector: <T>(selector: (s: RootState) => T) => T = useSelector;
```

## Por qué existe (respuesta a "¿why useAppDispatch over useDispatch?")

- `AppDispatch` ya trae el tipo del thunk → dispatching de acciones async devuelve un `Promise` tipado.
- Evita repetir `useDispatch<AppDispatch>()` o `dispatch(action() as any)` en cada componente.
- `RootState` tipa los selectors → `useAppSelector((s) => s.auth)` infiere el tipo de `auth`.

## Lectura vs escritura

- `useAppSelector(fn)` → **LEE** (fn recibe todo el `state`, devuelve un pedazo).
- `useAppDispatch()` → **ESCRIBE** (devuelve `dispatch`, que se llama con una acción).
